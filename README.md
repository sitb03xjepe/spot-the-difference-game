A complete spot-the-difference game in six hand-drawn worlds: Sunny Park, Cozy Kitchen, Deep Reef, Space Station, Old Library and Desert Oasis. Each level hides 7 differences between two side-by-side pictures drawn procedurally in code — find them all against the clock, with combo scoring, limited hints and a star rating per level. No libraries, no network requests, no assets: every scene, sound and marker is drawn or synthesised in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play. Or open `game/index.html` directly from any static file server. `main.ts` (Node 22) hands the game in: it copies `game/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
